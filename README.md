# AU Interaktif — After School

Template website AU statis yang bisa dipublikasikan dengan GitHub Pages.

## Fitur
- Lock screen bergaya iPhone dengan notifikasi yang bisa ditekan
- Home screen dan ikon aplikasi
- Chat AU interaktif dengan balasan simulasi
- Feed media sosial fiksi
- Photos, Notes, profil karakter, dan pengaturan wallpaper
- Cerita romance sekolah dengan pilihan dan episode
- Nama, wallpaper, dan progres pilihan disimpan di browser perangkat

## Cara publish ke GitHub Pages
1. Buat repository baru bernama `au-story` di https://github.com
2. Unggah `index.html` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
6. Tunggu proses selesai. Link akan berbentuk `https://USERNAME.github.io/au-story/`.

Ini simulasi website, bukan iOS sungguhan. Chat dan notifikasi yang tersedia adalah simulasi di dalam website; tidak terhubung ke WhatsApp atau Instagram asli.
